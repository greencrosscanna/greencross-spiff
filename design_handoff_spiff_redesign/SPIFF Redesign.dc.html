What changed
  • One program at a time is the standard, so the running program gets a card rather than a row in a table of one — with the Leaderboard's pace line under it, so "are we going to make it" is answered on sight.
  • A sub-nav like Crew's: search, scope segmented control, and store pills colored from the GX Core registry. SPIFF already loads GXStores at boot and uses none of it.
  • Import-from-Calculator is gone. It seeds history once; after that it is a button that can only do harm.
  • Closed programs keep a table, trimmed from twelve columns to eight — cost per unit and the payout model ride under the program name.
  • Flagged records tint the row and say what to do, rather than hiding the reason in a title attribute.

What changed
  • The two store lists are now one table. The old "Stores & baseline" cards duplicated the Per Store table's first two columns with no headers on them, which is why the columns read as unlabelled.
  • No participation checkboxes: every store runs every program, so the column was a control nobody would use. New stores appear from the GX Core registry.
  • "It scales with success" is the pitch the Calculator never made: the bounty is paid per budtender who actually hits, so cost tracks results.
  • The goal bar shows the ask as an extension past the reference period, with the Leaderboard's glow on the increase.
  • The payout model is a visible control. per_unit is real and implemented in the engine but the Calculator has no way to express it.
  • Cost-per-extra-unit and break-even fill the space the old layout left empty, and they are the two questions a vendor asks next.

Why a separate mode
  • The Calculator is a sales tool, but the working view is sized for a keyboard. This is the same model at reading distance across a desk.
  • Each store bar is split at today's number: the store's own color is where it is now, and the green extension — carrying Leaderboard's ahead-of-pace glow — is the increase being asked for.
  • Nothing internal is on screen: no per-store budtender counts to argue about, no save controls, no navigation.
  • Same numbers, same instant recompute — it is a stylesheet state, not a second calculator.
